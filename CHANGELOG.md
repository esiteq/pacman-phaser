### Виправлено
- Гра відображалась зі зсувом вправо і впритул обрізалась знизу на
  широких вікнах. Причина — `Phaser.Scale.CENTER_BOTH` в `main.js`
  одночасно з CSS-центруванням (`display:flex` на `#game-container`)
  застосовували центрування двічі: Phaser сам додавав
  `margin-left`/`margin-top` до канвасу, який flexbox вже центрував,
  зсуваючи гру. Тепер центрування виконує лише CSS
  (`autoCenter: Phaser.Scale.NO_CENTER`).
- `html`/`body`/`#game-container` більше не покладаються лише на
  `height: 100%`, яке на мобільному Safari рахується відносно "великого"
  viewport (коли адресний рядок прихований) — додано `100dvh` як
  прогресивне покращення, щоб контент не виїжджав під панель браузера
  після її появи. Заразом прибрано зайві `width/height: 100%` на
  `#game-container` (дублювали `inset: 0`, який для `position: fixed` сам
  по собі достатній і надійніший).
- Видалено `.github/workflows/jekyll-gh-pages.yml` — GitHub автоматично
  додав цей workflow при увімкненні Pages через UI; він паралельно з
  нашим `deploy.yml` намагався задеплоїти Jekyll-збірку репозиторію (не
  гру) в той самий Pages-простір, через що після push демо могло
  непередбачувано показувати то гру, то Jekyll-версію README, залежно
  від того, який workflow фінішував останнім.
- Заголовок "PAC-MAN" у HTML-шапці (`.header-buttons .title`) перекривав
  власний HUD гри ("1UP") на вузьких/портретних вікнах, де в канвасу
  майже немає лівого відступу — текст зливався в нечитабельне
  "PAC-MAN1P". Заголовок був суто декоративним (гра й так показує назву
  через свій HUD), тому видалений; кнопки паузи/звуку лишились,
  притиснуті праворуч.
- Стартова мелодія (`game_start`) ніколи не програвалась на щойно
  відкритій сторінці: `Audio.play()` викликається одразу при завантаженні
  сцени, до будь-якого жесту користувача, а браузери блокують
  автовідтворення звуку без нього (помилка гасилась мовчки через
  `.catch(() => {})`). Тепер `SoundManager` запам'ятовує заблокований
  звук і повторно програє його в `unlock()` — тому ж моменті першого
  keydown/pointerdown, який вже розблоковує `AudioContext` для
  ембієнс-звуків.
- Стартова мелодія (`game_start`) не програвалась на 2-му рівні й далі —
  `advanceLevel()` викликав `startGameplay()` без прапорця, який вмикає
  програвання мелодії. Виправлено: тепер грає на старті кожного рівня, і
  так само НЕ грає після втрати життя в межах того самого рівня (це
  лишилось без змін, як і просив користувач).

## [1.0.0] — базова лінія (ретроспективно)

Стан проєкту на момент першого технічного аудиту.

### Додано
- Порт [bward2/pacman-js](https://github.com/bward2/pacman-js) на Phaser 3
  (замість DOM/CSS-рендеру) з Vite як інструментом збірки.
- Фіксований таймстеп ігрового циклу (120 FPS логіки, інтерпольований
  рендер) — порт `gameEngine.js`.
- Гравець (Pacman), 4 привиди з індивідуальним ШІ (Blinky/Pinky/Inky/Clyde),
  режими scatter/chase/scared/eyes, Cruise Elroy.
- Оригінальний лабіринт 28×31 (244 крапки/пелети), той самий, що в
  bward2/pacman-js.
- Бонусні фрукти, комбо-очки за з'їдених привидів (100/200/400/800/1600),
  додаткове життя на 10 000 очок.
- Звук через Web Audio API (ембієнс-сирени, звук крапок з чергуванням
  буферів для мобільних).
- HUD: рахунок, рекорд (`localStorage`), життя, історія фруктів, пауза.
- Керування: стрілки/WASD, Esc — пауза, Q — звук, свайпи на мобільних.
- `README.md` українською з інструкціями запуску.
