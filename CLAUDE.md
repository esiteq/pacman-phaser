# CLAUDE.md

Інструкції для Claude Code (та інших агентів), що працюють у цьому репозиторії.

## Що це за проєкт

Класична аркадна гра Pac-Man, переписана на **Phaser 3** з нуля як порт
[bward2/pacman-js](https://github.com/bward2/pacman-js) (vanilla JS + DOM/CSS).
Ігрова логіка, таймінги, ШІ привидів і дані лабіринту збережені максимально
близько до оригіналу — змінився лише рушій рендерингу: DOM-елементи з
CSS `background-image`/`position` замінені на Phaser-спрайти й `Image`-об'єкти
на `<canvas>`.

Детальний технічний опис архітектури — у [TECHNICAL_DESCRIPTION.md](TECHNICAL_DESCRIPTION.md).
Історія сесій розробки — у [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md).
Список версійних змін — у [CHANGELOG.md](CHANGELOG.md).

## Команди

```bash
npm install       # встановити залежності
npm run dev        # dev-сервер Vite на http://localhost:8080
npm run build       # продакшн-збірка у dist/
npm run preview     # підняти локальний сервер і подивитись на dist/
```

Лінтера, тестів чи CI в проєкті немає — перевірка змін відбувається вручну
через `npm run dev` у браузері.

## Архітектура (коротко)

```
src/
  main.js              Boot: створює Phaser.Game, підв'язує кнопки паузи/звуку
  scenes/GameScene.js   Єдина сцена: preload/create/update, фіксований
                        таймстеп, HUD, потік раунду (ready → gra → смерть/
                        game over), обробка подій, таймери
  entities/
    Pacman.js           Рух гравця, спрайт-анімація, стрілка напрямку
    Ghost.js             Рух + ШІ всіх 4 привидів (одним класом, `name`
                          визначає поведінку), режими scatter/chase/scared/eyes
    Pickup.js             Крапки, пелети, бонусні фрукти — рендер + колізії
  utils/
    CharacterUtil.js      Чиста математика сітки/руху/колізій (без Phaser)
    Timer.js              Пауза-сумісний setTimeout-обгортка на CustomEvent
    SoundManager.js        Web Audio: ембієнс-звуки, окремий контекст для
                            звуку крапок (щоб не заникало на мобільних)
    mazeData.js             Масив лабіринту 28×31, розміри тайлів, точки/
                             зображення фруктів
public/assets/           графіка (PNG) і звук (MP3), взяті напряму з
                          оригінального репозиторію
```

Гра керується через **window CustomEvents** (`dotEaten`, `powerUp`,
`eatGhost`, `deathSequence`, `awardPoints`, `addTimer`/`removeTimer`, тощо) —
це прямий порт event-based координації з оригінального `gameCoordinator.js`.
Коли додаєш нову ігрову подію, тримайся цього ж патерну, а не пропсів/колбеків.

## Важливі принципи при зміні коду

- **Це порт, а не переписування.** `CharacterUtil`, `Ghost`, `Pacman`, `Timer`
  — математика руху/колізій/AI в них має лишатись ідентичною оригіналу
  bward2/pacman-js. Якщо треба щось змінити в ігровій логіці — переконайся,
  що це свідоме рішення, а не випадкове відхилення від оригіналу.
- Фіксований таймстеп (`GameScene.update` → `processFrames`/`draw`) відділяє
  логіку (кроки по `timestep` = 1000/120мс) від рендеру (інтерпольований draw
  через `interp`). Не змінюй цю модель, не розібравшись, як вона впливає на
  плавність анімації.
- `pixelArt: true` + `antialias: false` в конфізі Phaser (`main.js`) — для
  чіткої піксель-арт графіки. Текстові об'єкти Phaser (`makeText` у
  `GameScene`) навмисно перемикаються назад на `LINEAR`-фільтрацію, інакше
  текст рендериться побитими блоками — не прибирай це.
- Дані лабіринту (`mazeData.js`) — той самий масив 244 крапок/пелетів, що і в
  оригіналі. Якщо редагуєш лабіринт, звір розмір з рядками `RAW_MAZE` (28
  колонок × 31 рядок).
- Рахунок і рекорд зберігаються в `localStorage`
  (`pacmanPhaserHighScore`, `pacmanPhaserVolume`) — прямі ключі, без обгортки.
- Стиль коду: без крапки з комою... ні, з крапкою з комою, camelCase, класи
  через `export default class`. Коментарі — мінімальні, лише там, де
  пояснюють нетривіальне рішення (дивись існуючі файли як приклад тону).

скрипт збірки) — онови відповідний розділ у `TECHNICAL_DESCRIPTION.md` і

запис у `DEVELOPMENT_LOG.md` (що зроблено, чому, які рішення прийняті).
